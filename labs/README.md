# Kafka Labs

Recommended practical sequence:

1. Install Kafka.
2. Create a topic.
3. Produce messages.
4. Consume messages.
5. Create a consumer group.
6. Scale consumers.
7. Observe consumer lag.
8. Build a multi-broker cluster.
9. Test replication.
10. Simulate broker failure.
11. Configure retention.
12. Configure Kafka Connect.
13. Configure Schema Registry.
14. Configure Kafka security.
15. Monitor Kafka with Prometheus and Grafana.
16. Run Kafka using Docker.
17. Run Kafka using Kubernetes.
18. Implement retry and DLT.
19. Troubleshoot production scenarios.
20. Complete the e-commerce capstone.
